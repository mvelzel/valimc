# VMC-014b1 — Position-dependent collision shapes

Status: Done
Note: Done — position-only geometry validated. October 14, 2026. Depends on VMC-014a; the full contextual-shape subsystem remains incomplete.

Resolve the 52 bamboo, pointed-dripstone and sulfur-spike states whose collision
geometry depends only on block position. Other dynamic contexts stay unresolved;
world queries and movement enforcement remain VMC-014b/VMC-014c.

Acceptance:

- Extract native unshifted grids and horizontal-offset limits for all 52 states.
  Record the pinned jar/hash; regenerate facts independently in the native check.
- Implement pure position-aware lookup with native signed 32/64-bit overflow,
  arithmetic shifts, single-precision division and clamping. Validate coordinates;
  never guess another contextual shape. Geometry stays block-local until moved.
- Compare native offsets, grids and clipping at positive/negative coordinates,
  column-height changes and world boundaries; test malformed positions and IDs.
- Pass format, full tests/native oracle, production release and public-tree audit.
- Actual Minecraft 26.3/CUA: render these three offset block families, walk into
  prepared columns, compare observed contacts with position-aware geometry,
  then verify a command and reconnect. Client physics remains the contact source.
