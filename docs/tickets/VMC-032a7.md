# VMC-032a7 — Atomic block/container storage

Status: Implementing; no new live block/menu admission.

Acceptance: extend the existing leased region write-ahead commit to include an
optional complete container snapshot alongside changed blocks and the item ledger.
Recover all three before ownership admission after a crash at any file boundary.
A failed/uncertain write cannot acknowledge or expose a partial proposal. Preserve
existing v1 journals exactly, bound/validate the new format and reject malformed,
wrong-region or corrupt nested snapshots. Never erase a journal before all outputs
are durable. This foundation precedes physical chest placement/removal; it does
not itself enable them. Target codec/lease/writer-death/recovery regressions and
carry a dedicated baseline on the next immutable checkpoint before publication.
