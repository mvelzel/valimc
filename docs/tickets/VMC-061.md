# VMC-061 — Concise docs and targeted retrieval

Status: Planned — deferred at the user's request, October 14, 2026.

README and other Markdown files are too long and repetitive, consuming context
before useful development begins. Clean up the documentation after the active
implementation work; do not start this ticket merely to log the feedback.

Acceptance:

- Keep README to purpose, quick start, current limitations and relevant links.
- Remove repetition and verbose wording throughout the docs. Move detailed
  evidence/history into focused records where it still has value.
- Provide a small entry point to current state, active ticket, next dependencies
  and the relevant reference/test records. Agents should read selectively.
- Make roadmap lookup, status updates and evidence logging quick and consistent.
- Preserve accurate compatibility gaps, pending validation gates, provenance and
  development requirements; concise must not mean losing essential context.
- Verify the workflow by finding and continuing a ticket without loading large
  unrelated documents. Record which files were needed.
