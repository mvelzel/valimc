# VMC-002 — Advertise executable custom commands to the client

Status: Planned. Updated: October 13, 2026. Depends on VMC-001.

## Scope and acceptance

The preview executes `/help`, `/stats` and `/spawn`, but sends no command graph,
so the vanilla client cannot validate/complete them locally. Publish these three
supported no-argument commands from a single catalog used by graph, help and
server dispatch.

- Mojang's 26.3 decoder reconstructs executable literal nodes.
- Actual-client completion suggests supported commands; `/sta` + Tab becomes
  `/stats`, executes and shows the response.
- `/help` matches the catalog, `/spawn` still teleports, and unknown names or
  extra arguments cannot dispatch a valid command accidentally.
- Argument parsers, permissions/plugins and full vanilla commands remain future
  work. The graph contains no advertised but unimplemented command.

## References and design

Pending inspection: vanilla `ClientboundCommandsPacket`/Brigadier, Pumpkin tree
generation, SteelMC node encoding, and Paper command patches. Use an immutable
catalog; execution stays in the owning connection, with no global dispatch owner.
