# VMC-004b1 — Bounded network NBT and custom item data

Status: Done
Note: Done — local, unpushed. Updated: October 13, 2026. Depends on tested VMC-004a.

## Scope and acceptance

Add pure bounded unnamed network NBT, then support custom item data in both
stack formats. This establishes reusable binary handling for structured items
and future vanilla storage without adding a runtime JVM or a process per tag.

- All twelve NBT tag types, nested compounds/homogeneous lists and dense arrays
  parse/encode with explicit byte/node/depth budgets. Unknown tags, duplicate
  compound names, truncated/negative arrays and illegal list declarations fail.
- Strings use Java modified UTF-8, including NUL and supplementary Unicode;
  reject malformed encoding and unsupported unpaired surrogates explicitly.
- Preserve floating-point bit patterns, including non-finite values inside
  opaque custom data. Gameplay schemas will validate their own finite values.
- Custom data accepts only compound roots and stays uninterpreted. No entity,
  block-entity or gameplay mutation is authorized by arbitrary custom NBT.
- Mojang generates custom-data fixtures and decodes Elixir's converted bytes;
  actual TCP tests preserve custom data through slot/click updates.
- Resource-limit failures affect only the input session. Raw dumps/fixtures
  remain private and ignored; only original code/protocol facts are committed.

Actual-client scenario: select a custom-data fixture item,
move/split it through inventory, place its ordinary block and reconnect to verify
the existing pose baseline. Names/lore and other component schemas will follow.
This is network NBT, not Anvil/world-file import or full structured-item parity.

## References and design

Pinned vanilla 26.3 jar `33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`:
`NbtIo`, tag payload readers/writers, `StringTag`, Java `DataInput.readUTF`,
`CustomData.STREAM_CODEC`, and `DataComponents.CUSTOM_DATA`.
Private bytecode/fixtures remain ignored. Dense primitive arrays and raw float
bits stay immutable binaries; compound/list structure stays in the connection's
accepted stack. Explicit budgets prevent decoder work/heap growth independent
of outer packet compression. No global NBT owner or task per field.

## Verification

October 13, 2026: all 58 ExUnit tests, formatting and production release pass.
Mojang generates nine stack fixtures, including all twelve NBT tag payloads,
NUL/supplementary Unicode, NaN and infinity. Both Elixir stack formats round-trip
through Mojang's codecs with semantic equality. Mojang's component codec also
decodes Elixir's Unicode system text. The full TCP oracle passes the 49-chunk
baseline and preserves custom data through creative/click/hand updates.
Independent byte/node/depth limits and malformed payloads are covered; a TCP
depth-exhaustion regression rejects only its submitting session. Public-tree
audit/self-tests pass. Private oracle/release logs are under `/tmp/`.

isolated SDL event-position adapter, a 17-stone fixture with glint and custom NBT
was split, placed one at a time, merged and shift-transferred in the creative
inventory. A read-only owner-state check confirmed count 17, unchanged custom
data (including NUL and emoji), and glint after the client's edits. Ordinary

gameplay semantics, ordinary drag compatibility or item persistence is claimed.
