# VMC-005b1 — Bounded inventory clicks and basic transactions

Status: Awaiting client validation. Updated: October 13, 2026. Depends on tested VMC-004a/005a.

## Scope and acceptance

Replace header-only click restoration with a complete bounded 26.3 click decoder
and authoritative basic player-menu operations.

- Parse predicted hashed stacks, changed-slot maps and component hash/removal
  sets; bound packet/counts/IDs and reject malformed, duplicate, trailing input.
  Never create items or components from prediction claims.
- Ordinary left/right pickup, half splitting, one-item placement, compatible
  merging, swaps and main/hotbar shift transfers preserve counts/components.
- Number-key and offhand swaps are atomic. Read slot restrictions from the pinned
  default equippable metadata; unsupported crafting/drag/drop/clone cases restore
  authoritative state and remain subsequent tickets.
- Execute supported clicks against current owner state even if the supplied
  state ID is stale, then restore a complete accepted snapshot/cursor. Vanilla
  uses state mismatch to choose replication, not as inventory authority.
- Bound aggregate encoded inventory size so every correction fits the protocol
  packet limit. A rejected operation preserves the previous owner state.
- Tests cover conservation, split/merge caps, mismatching patches, stale/forged
  predictions, restrictions, unsupported cases, packet boundaries and isolation.
  Mojang generates prediction fixtures and exercises resulting changes over TCP.

Actual-client scenario, queued: inventory-tab pickup, right-half pickup, placing
one, merge, shift and number-key/offhand swap; verify cursor and counts. Exercise
an unsupported operation and reopen the menu. Close/return/drop behavior,
crafting, drag/collect, persistence and survival lifecycle are subsequent slices.

## Verification

October 13, 2026: all 51 ExUnit tests, formatting, production release,
Mojang's two-format stack checks and expanded full TCP oracle pass. Public-tree
audit/self-tests and exact-diff checks pass.
Implemented bounded full hashed-click parsing, scalar patch preservation,
ordinary pickup/split/place/merge, compatible shift transfer, default armor
auto-equip and restricted armor insertion, number-key/offhand swaps. Predictions
never construct owned stacks; stale input applies to the current owner state and
receives full corrections. Item-specific stacking overrides (e.g. bundles) are
identified from the official runtime and explicitly rejected until their rules
are implemented. Full snapshots trade packet volume for correctness at this
stage; no performance improvement is claimed.

Meaningful regression cases include 300 deterministic mixed clicks conserving
item/component totals, merge caps, sparse clearing, armor restrictions, known
unsupported behavior, 512 KiB aggregate encoding budget, truncation at every
prediction boundary, duplicates/unknown IDs/count limits, forged component
hashes and a forged diamond cursor, stale state, and failure isolation.

The extended Mojang TCP scenario exercises nonempty hash/removal observations
and verifies pickup, placing one, merging, shift, number-key/offhand swap and
cursor snapshots from the server. These are official wire checks plus explicit
expected behaviors, not a differential vanilla gameplay-server run.

Actual 26.3 computer use, October 13, 2026: a development-only game-event
fixture selected the ordinary player-menu UI (the server still has creative
preview rules). A right pickup of 17 component-bearing stones left 8 in the
hotbar and 9 in the authoritative cursor, confirmed by an owner-state read.
A carried-item placement generated quick-craft packets and restored state with
an unsupported-operation message. This slice deliberately rejects quick-craft;
its full place/merge/shift/swap GUI scenario remains pending until VMC-005b2a.
Creative inventory-tab edits use a different packet path and do not substitute
for that verification. Focused private client bytecode for
`AbstractContainerScreen.mouseClicked/mouseDragged/mouseReleased/quickCraftToSlots`
records this distinction. No full graphical click pass is claimed.

Cursor return on close, drop entities,
drag/collect, crafting and inventory persistence remain later slices. Closing a
menu currently preserves the cursor in server state and resends it; it does not
yet implement vanilla's cursor-return/drop lifecycle. The VMC-005 subsystem
remains incomplete.
