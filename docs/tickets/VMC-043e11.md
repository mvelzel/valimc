# VMC-043e11 — Turtle-egg placement events

Status: Done
Milestone: M3
Depends on: [VMC-043e6](VMC-043e6.md).

Complete the turtle egg's native placement hook. A changed egg state on a
sand-tag block emits level event 2012 with data 15, including an egg laid by
a turtle and changes to an existing egg's count or hatch state. An unchanged
state, a non-sand surface or a suppressed placement hook emits none.

Acceptance:

- Native placement calls match the live block-update engine for every egg
  count and hatch state, sand/red sand and non-sand supports, old states and
  positions on both sides of a section line.
- The existing group-owned block edit produces the event in the same
  frame; no extra process, timer or gameplay authority is introduced.
- Affected Rust, block/owner and native checks pass. Actual-client
  observations remain deferred by the user.

Reference: Mojang 26.3 server SHA-1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`, `TurtleEggBlock.onPlace`,
`TurtleEggBlock.onSand` and `LevelChunk.setBlockState`. The chunk calls
`onPlace` for changed properties of the same block too, except with
`UPDATE_SKIP_ON_PLACE` (512). The placement event uses the generated
`minecraft:sand` block tag.

Implementation: the shared block-update hook emits the placement event
after the new egg state is installed, using the generated sand tag. It
respects the native placement-suppression flag and reads only the owning
group's cells. Ordinary laying, player placement and property changes use
this same path; the existing event result is published with the block edit.

Evidence (October 24, 2026):

- `TurtleEggPlaceOracle` runs native block placement for all 12 egg states,
  four old states, four surfaces and positions on both sides of a section
  line: 384 cases, with exactly 184 native placement events. The live
  `BlockRules.run` path matches all cases.
- The broad affected run passes 102 of 103 stages in 337 seconds, with
  127 cache hits and no unverified extraction. The new checker initially
  depended on application startup to install block flags; making it install
  its rules explicitly fixes standalone operation, and its isolated stage
  passes. Logs: `.local/m3-turtle-egg-changed.log` and
  `.local/m3-turtle-egg-stage.log`. No gameplay change was needed for this
  checker initialization fix.
- All 124 core Rust tests, workspace Clippy (existing unrelated warnings),
  three turtle-egg tests, formatting and public-tree/layering audits pass.

Actual-client observation is deferred: watch the particles when a turtle
lays eggs and when a player adds eggs on sand or red sand, then compare a
non-sand surface. The family's other client scenarios remain pending.
