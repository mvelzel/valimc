## References and design

Vanilla 26.3 provides exact semantics, Paper provides edge cases, and incomplete
Pumpkin/SteelMC and other rewrites provide subsystem ideas. `research.md` records
the expanded comparison; `sources.lock.json` pins every downloaded source.

Copying the official Java executable under a changed Info.plist invalidates its
signature. Our original small launcher uses OpenJDK's existing `libjli` entry
point inside a macOS app bundle. The official runtime and Minecraft classes stay
intact; local paths/binaries are generated only under `.local/`.
