# VMC-007c1 — Bounded Mojang session lookup foundation

Status: Done — foundation and client smoke validated, local. Updated: October 14, 2026.
Depends on VMC-007a/b. Does not enable online mode by itself.

## Acceptance and client scenario

- Declare OTP SSL dependencies and use verified TLS/hostname checks/system
  roots. No shell HTTP tool, insecure certificate option, redirect following,
  token handling or new Hex dependency in the runtime.
- Lookup uses the pinned production session verify endpoint, validated username
  and signed native digest. Bound time, response headers/body and JSON structure;
  preserve returned UUID and exact property values/signatures. Native hasJoined
  uses the requested name rather than trusting a returned name. Fail closed on
  missing/invalid identity, malformed JSON, oversized response or TLS failure.
- Execute blocking lookup only from the later bounded authentication workers;
  this foundation is not wired into gameplay/socket owners. VMC-007c2 integrates
  job ownership/cancellation/deadlines before granting a player lease.
- Test a trusted local TLS fixture and untrusted/wrong-host certificates,
  non-success statuses, redirects, slow/oversized/chunked bodies, schema limits
  and native profile/property codec agreement. Tests never use real account tokens.
- Format, full tests, production release, native oracle, public audit/exact diff.

Actual Minecraft 26.3 / CUA: baseline smoke after adding runtime OTP applications:
join localhost, render the existing world and inventory, run `/stats`, reconnect;
retain fresh inventory/pose/sequence. This is a foundation smoke gate, not proof
of online authentication. Licensed-client online validation belongs to VMC-007c2.

## References and decisions

Pinned Mojang 26.3 ServerLoginPacketListenerImpl/its authentication thread and
authlib 10.0.77 MinecraftServicesSessionService, MinecraftServicesDiscoveryService,
HasJoinedMinecraftServerResponse and GameProfile. Private bytecode is in ignored
`research/disassembly/VMC007-*.txt`. Authlib discovers SESSION/verify; the official
production discovery document observed October 14 maps it to
`https://sessionserver.mojang.com/session/minecraft/hasJoined`. Dynamic refresh
remains VMC-007c3. Response properties are retained; no fake skin/signature data.

OTP 29.1.1 SSL/public_key/inets are installed correctly. Earlier no-start Mix probes
pruned undeclared applications from the code path, giving a misleading missing
module result. Declaring dependencies resolves it; no installation repair needed.
Use [OTP SSL](https://www.erlang.org/docs/29/apps/ssl/ssl.html) and
[httpc](https://www.erlang.org/doc/apps/inets/httpc.html) primary documentation.
OTP 29 httpc supports cumulative header and framed-body bounds, but its
close-delimited path can accumulate input before the final size check. A trusted
local TLS regression demonstrated this. The implementation therefore uses a
passive worker-owned SSL socket and OTP's HTTP header decoder, with explicit
Content-Length/chunked/close-delimited body limits while reading. No generic
connection pool or request handler survives worker death. No inets dependency
is needed. This deliberately narrow GET transport accepts HTTP/1.0/1.1, identity
encoding and bounded chunk extensions/trailers; it does not follow redirects.
Bodies cap at 64 KiB, headers and chunk metadata independently at 8 KiB, deadlines
at five seconds; JSON has eight nesting levels and bounded strings/entries/numbers.
Profiles retain up to 16 string-valued properties. Malformed/ambiguous identity,
duplicate JSON keys/framing headers and unsupported response encodings fail closed.

## Verification

October 14: format, **298 tests** (seed 220044), production release, full native
plaintext/encrypted suites, public-tree audit and exact diff pass. Eleven new
regressions cover trusted TLS, unknown CA, wrong hostname, redirects, HTTP-only
URLs, timeouts, cumulative headers, declared/chunked/close-delimited body limits,
fragmented chunks/trailers, ambiguous/truncated/encoded framing, abrupt worker
death and bounded duplicate-key/schema/JSON failures. Negative HTTP cases verify
that the trusted fixture actually received a request before rejection, avoiding
false passes from broken TLS fixtures. Certificates/keys are generated in memory
with OTP test helpers, SHA-256 and P-256; no real account tokens are used.

The independent native harness uses authlib 10.0.77 ObjectMapper,
HasJoinedMinecraftServerResponse and GameProfile for **32 synthetic cases**:
compact/hyphenated UUIDs, requested-name preservation, absent/null/empty properties,
one/16 entries and exact signed/unsigned values containing Unicode/NUL. Comparison
ignores property iteration order while retaining every value/signature. Generated
fixture JSON and bytecode stay private; the full oracle cleans its temporary files.
Supported production array-shaped properties are covered; authlib's legacy
object-shaped/coerced property JSON remains unsupported and fails closed.

The packaged release completed a verified production discovery GET (200, 2264
bytes), establishing that SSL/root certificates work outside the development VM.
The earlier apparent missing-module issue came from no-start Mix code-path pruning;
no reinstall was performed. Private logs: `.local/vmc007c1-{tests,release,oracle}.log`.
