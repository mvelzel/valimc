## Acceptance

- Add explicit online-mode configuration, default false. Online mode always
  requests encryption with native authenticate=true, irrespective of the optional
  offline encryption setting. Never permit online plaintext or offline fallback.
- After key proof, create the socket-owned cipher and compute the native signed
  digest; dispatch one bounded HTTPS job. Allocate/publish a player and UUID writer
  lease only after a matching timely authenticated result. Clear temporary secret/
  challenge material. Preserve bounded coalesced input and compression transitions.
- Use supervised cold authentication workers with capped admission, absolute
  deadlines, owner/worker monitors, cancellation and stale-result fences. Requests
  stay outside socket/tick owners; abrupt owner loss closes the worker's TLS socket.
  Saturation, outages, malformed profiles and timeout affect only their peer.
- Native returned UUID and exact properties reach login and player-info codecs.
  Preserve the requested name as pinned authlib does. Offline UUID saves remain
  separate; no automatic offline/online file migration. Reconnect fencing follows
  the authenticated UUID, including pending durable transfer recovery.
- Add meaningful success/rejection/replay/capacity/deadline/worker-failure/lease
  isolation tests with a synthetic provider. Native codecs independently validate
  signed/unsigned profile properties. Never use account tokens in tests or logs.
- Format, full tests, release, full native oracle, public audit/exact diff.
