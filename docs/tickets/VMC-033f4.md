# VMC-033f4 — Live owned table menus

Status: In progress. October16,2026. Parent: VMC-033f.

Acceptance: actual placed-table use opens the46-slot3×3 menu. Validate normal,
secondary and spectator access, per-session container IDs, current authoritative
block/reach and stale-owner/deadline refusal. Craft ordinary recipes and result
gestures through owned inputs. Closing, removal, movement, relocation, death,
disconnect and fresh reconnect conserve inputs/cursor/output, including overflow
beyond the existing five-record transfer budget.

Ownership: the connection owns menu context and all nine transient inputs. The
region authorizes one operation against its current block, epoch and an expiring
player grant; permission linearizes at that owner decision. A grant is consumed
only by its matching unchanged connection context. Serialize pending clicks in a
bounded connection queue; do not use ETS observations as permission. Recheck idle
menus and close on invalid context. No per-table inventory/process or shared menu
state. Retire container IDs/context before cleanup; lock further inventory actions
while bounded durable batches drain. Existing source/outbox and destination
receipts handle crash/reconnect, including partially completed cleanup.

wrong/full cursor, removed/out-of-range table, overflow and fresh reconnect.
