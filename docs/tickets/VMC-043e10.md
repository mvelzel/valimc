# VMC-043e10 — Ageable ocean mobs

Status: Awaiting client
Milestone: M3
Depends on: [VMC-043e9](VMC-043e9.md).

Finish the ageable-water-creature behavior of dolphins, squid and glow
squid. Preserve each type's native pack baby chance, baby dimensions and
age state; babies grow up, respect age locks and retain their age over
storage. Feeding a baby dolphin advances its growth instead of marking it
for treasure, and a baby cannot attack.

Acceptance:

- Native 26.3 pack traces cover all three types, including baby chances
  and random transitions, using the existing shared pack admission.
- Generated native facts supply baby dimensions and species-specific
  chances; common ageing and feeding rules are shared with existing ageable
  animals rather than independently copied into each mob family.
- Legacy stored dolphins and squid load with the new age fields defaulted,
  preserving all existing entity data. Unknown or malformed data is still
  refused.
- Headless native checks and affected owner tests pass. Actual-client
  observations remain deferred at the user's request.

Reference: Mojang 26.3 server SHA-1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`, `AgeableMob`,
`animal.AgeableWaterCreature`, `Dolphin` and `Squid`. Native dolphin
finalization supplies `AgeableMobGroupData(0.1F)` and squid supplies
`AgeableMobGroupData(0.05F)`; the first member has no baby roll. Dolphin's
baby dimensions include a distinct eye height, and its baby `canAttack`
returns false. Fish remain outside this ageable hierarchy.

Implementation: the existing pack admission now handles all three types,
using the native chances and baby dimensions extracted into `animal_facts`.
Their live bodies carry age, forced age and age lock; squid's existing age
counts now respect locks, and dolphins share the same ageing and feeding
primitives as farm animals. Baby voices use the shared higher pitch.
Native dolphin feeding advances a growing baby's age and starts its particle
timer; an age-locked baby instead takes the ordinary `GotFish` branch.
Babies cannot acquire an attack target. Exact legacy record shapes gain
only the new defaults; unknown keys, missing former fields and malformed
new age fields remain invalid. No world reset is required.
The live NoAI settlement path is completed and covered by owner/native
traces in [VMC-043e12](VMC-043e12.md).
