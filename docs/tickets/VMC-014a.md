# VMC-014a — Cached block collision geometry

Status: Foundation
Note: Done — cached geometry foundation validated. Updated: October 14, 2026.

## Scope and acceptance

Before this ticket the server had no block collision geometry. Movement still
accepts client coordinates. Establish cached native block-state shapes and pure collision
operations before integrating movement/pose checks. This is a dependency of full
VMC-014, not an alternate completion criterion for it.

- Extract every pinned block state's cached collision shape with its voxel grid
  and occupied cells. Deduplicate immutable geometry. States with dynamic shapes
  must return an explicit context requirement, never an empty/full-box guess.
  Unknown state IDs reject. Preserve shapes extending outside a unit cube.
- Validate catalog bounds/invariants and compare regeneration against the pinned
  native state registry. Public data contains geometric facts, not source/assets;
  oracle cases, bytecode and test worlds stay ignored.
- Implement pure bounded shape translation, box intersection and axis clipping
  with native epsilon/ordering. Test contacts, overlap, tiny deltas, internal grid
  boundaries, negative coordinates, compound shapes and all three axes against
  actual Mojang shape methods. No process per shape/block is introduced.
- Keep geometry immutable/shared and computation separate from region ownership.
  Movement integration must later obtain fenced authoritative block observations
  and define tick/boundary ordering; replication ETS is insufficient.
- Pass format/full tests/native oracle/release/diff review/public-tree audit.

Actual Minecraft 26.3 / CUA: render representative stone, slab, stairs and fence
fixtures. Generate actual keyboard movement/contact observations and compare them
with catalog geometry and pure clipping queries for the same fixture. Confirm
commands and reconnect. This checks the geometry foundation against client
behavior; movement is still client-controlled and must not be reported as server
collision enforcement. Dynamic collision contexts and physics require later tests.
