# VMC-043e13 — Puffing beside collision shapes

Status: Done
Milestone: M3
Depends on: [VMC-043e12](VMC-043e12.md).

Replace the pufferfish's empty-space-only resize approximation with native
collision displacement. When a fish grows, vanilla searches for the
nearest available center inside a small growth volume; walls and partial
shapes can move it sideways or vertically. The current implementation
keeps its position when the enlarged box is obstructed.

Acceptance:

- Native pufferfish dimension changes match position and dimensions for
  both ordinary growth steps, full and partial collision shapes, corners,
  narrow gaps and the native old-height fallback.
- The geometric search is pure and bounded to the fish's local growth
  volume; reads use the existing immutable world view and no new owner.
- Targeted tests and affected native stages pass; actual-client testing
  remains deferred by the user.

Reference: Mojang 26.3 server SHA-1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`,
`Pufferfish.setPuffState`, `Entity.refreshDimensions`,
`Entity.fudgePositionAfterSizeChange`, `CollisionGetter.findFreePosition`
and `VoxelShape.closestPointTo`. Native search subtracts collision boxes
inflated by half the requested dimensions from the growth volume and finds
its nearest point to the old center. A second search may retain the old
height when both dimensions grow, adding its native vertical epsilon.

Implementation: a pure local box-subtraction search finds the nearest
remaining point to the old center. The AI reads the existing immutable
block view, and unknown cells refuse displacement. The search is limited
to a pufferfish's growth dimensions. Full blocks and static partial shapes
reuse the existing collision palette; contextual shapes use a production
accessor into the movement kernel's generated geometry with the fish's
actual bottom and fall distance. This is needed to keep a fish resting on
scaffolding from being resized through its surface. No new fact table,
process or authority is introduced.

Evidence (October 24, 2026):

- The original checker reproduces a ceiling failure: a fish at Y64.6 kept
  that position while native puffing moves it to Y64.51000002026558.
  The first context-free search also reproduced sinking through scaffolding
  at Y65; using the movement context matches native Y65 exactly.
- `puffer_resize` passes 3,315 native position/dimension cases: both growth
  steps, full blocks, slabs, stairs, snow, honey, fences, trapdoors,
  scaffolding, powder snow, corners, narrow gaps, the old-height fallback
  and a small world border. Only initially unobstructed native bodies enter
  the fixtures.
- `block_collision` extends its 11,393 native collider cases to compare the
  production geometry accessor's collision cells. Its existing 14,238
  block-entity-snapshot exclusions remain unchanged.
- Five affected ExUnit tests pass, including unknown-cell refusal and the
  live pufferfish contact and shield/socket regressions.
- Seven named affected stages pass: resize and block collision (five seconds),
  then AI, mob travel, paths, combat and TCP (89 seconds). The latter includes
  18,063 ticks in 54 AI scenes. Named areas keep independent profiler work
  in the shared checkout out of this slice's check selection.
- The changed NIF crate's tests, workspace Clippy (existing unrelated
  warnings) and a no-parity production check pass; the accessor lives in
  the production physics shim. Formatting and public-tree/layering audits pass.
