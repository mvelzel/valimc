# VMC-014c4 — Live player movement reconciliation

Status: Post-move predicates verified; live integration pending. October 15, 2026.
Depends on VMC-014c3b2b2.

Replace unconditional position acceptance with player-owned bounded geometry
validation and native-compatible corrections. Keep independent players concurrent;
no global gameplay process or speculative storage-region merges.

Acceptance:

- Validate the swept player body, steps and newly entered collision shapes;
  distinguish creative/spectator/impulse allowances and impossible movement.
- Ordered bounded inputs/jobs; commit only the current input/owner incarnation.
  A timeout/source loss never authorizes passage through missing geometry.
  Correction and teleport acknowledgment fence late work, including `/spawn`.
- Preserve walk, flight, crouch/crawl, stepping and sliding in the real client.
  Probe forged wall entry/large deltas, concurrent players, source replacement,
  blocked geometry and delayed input/results with targeted tests/native codecs.
- Use server-authorized teleport fixtures when older tests relied on forged
  large movement packets; retain their spatial visibility coverage.

Reference: pinned Mojang 26.3 server SHA1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`,
`ServerGamePacketListenerImpl.handleMovePlayer`, `handlePlayerPositionChange` and

The handler checks newly entered shapes even in creative; moved-wrongly allowances
do not mean creative players can enter solid walls. Shape checks deflate both
boxes by native float-promoted `1e-5`. Existing clipping/step primitives retain
their native evidence; packet acceptance is a separate decision.

Implemented: pure moved-wrongly allowances, newly entered shape detection and
awake-player collision rejection. `ServerMovementOracle` invokes the actual
private packet handler on isolated controlled players/worlds, supplying the moved
position and occupancy; it does not replace that handler's decision algorithm.
All four modes, impulse/dimension/noclip flags, strict error boundaries, vertical
residuals, existing/compound/new overlap and deflation boundaries are covered at
local/negative/remote coordinates. 20,736 native decisions match Elixir; 14 affected
clipping/step/pose/predicate tests pass. Raw cases/logs: `.local/server-movement-*`.
The broader integration driver includes this oracle for the next coherent block.
