# VMC-014b6c2 — Supplied-observation collider collection

Status: Done — validated. October 15, 2026. Depends on VMC-014b6c1.

Collect ordered block colliders from bounded supplied owner observations and
explicit entity/block-entity contexts. Preserve input fences, reject conflicting
or incomplete observations, and match native full-block versus voxel overlap.
No world reads or gameplay authority are introduced by this pure calculation.

Acceptance:

- Match actual `BlockCollisions` ordered positions and geometry across cached
  grids, position/entity/BE contexts, compounds, boundaries and world offsets.
- Preserve native shared-full-block identity through geometry operations; strict
  AABB overlap differs from voxel AND on thin/epsilon queries. Probe both paths.
- Return missing/unknown state and unresolved/invalid contexts explicitly. Reject
  conflicting owner incarnations/revisions, foreign blocks and oversized inputs.
  Cap candidate/result work; never return an approximation after a limit failure.
- Preserve owner/revision fences for later validation. A collected result is not
  proof that observations are simultaneous or still current at gameplay commit.
- Pass format, full tests/native suite, release, exact diff and public audit.

  and compare stair lower/upper or fence contacts. Exercise missing-state/context

unknown IDs, conflicting batches/fences, foreign blocks and unresolved contexts
