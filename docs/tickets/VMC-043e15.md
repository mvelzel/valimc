# VMC-043e15 — Shulker targeting uses the physical lid

Status: Awaiting client
Milestone: M3
Depends on: [VMC-043e1](VMC-043e1.md), [VMC-037o](VMC-037o.md).

A shulker's physical box follows its opening lid in all six directions.
Projectile targets and player attack/interaction reach must use that box,
including when the lid extends across a section border. Reuse the family's
existing box hook through one body-box accessor; do not derive these targets
from type dimensions. AI sensing already uses the family hook.

Acceptance:

- Physical boxes match pinned native shulkers for all attachment faces,
  partial and full opening, and positive/negative positions.
- A real owner's arrow can hit an open lid outside the closed cube across
  a section border; the same shot misses a closed shulker.
- Player attack reach includes the physical lid. Dragon part boxes and the
  offset fence-knot box keep their existing handling.
- Actual-client observations remain deferred at the user's request.

Reference: Mojang 26.3 server SHA-1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`, `Shulker.makeBoundingBox`,
`getPhysicalPeek`, `getProgressAabb`, `ProjectileUtil.getEntityHitResult`
and `ServerGamePacketListenerImpl.handleAttack`'s interaction-range check.
This slice covers targeting geometry; solid movement collision and opening
lid displacement remain follow-ups.

Implementation: `Body.box/2` uses the family's physical geometry, falling
back to its current dimensions. Projectile targets use it directly; compact
nearby-player observations carry the resulting box so attack and interaction
reach can use it without copying an entire mob body. The raw peek can stay
unchanged while the physical lid animates, so publication includes the
physical box in each row's change detection. AI sensing already had the hook.

Validation: 378 actual native boxes and 2646 native arrow segments
match, covering six faces, 21 peek amounts and three positions. The original
cross-section arrow regression failed at 30 health; it now hits the open
lid for six damage and still misses the closed cube. The player socket
regression accepts an open lid within the server's buffered reach while
refusing the same closed cube. Combat/projectile suites pass 26 tests;
tracker, replication and body suites pass 15. All 32 affected vanilla stages
pass (176 seconds, 35 cache hits), with the final physical-box and plain/
encrypted TCP stages passing after the compact publication change. Evidence:
`.local/m3-shulker-box-{before,native,check,tests,tracking-tests,changed}.log`.

Deferred actual-client scenario: arrows and melee hit an open shulker lid
beyond its closed cube; repeat with floor, wall and ceiling attachments.
