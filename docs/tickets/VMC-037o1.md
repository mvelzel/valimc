# VMC-037o1 — Projectile hits across the owning group

Status: Awaiting client
Milestone: M3
Depends on: [VMC-037o](VMC-037o.md), [VMC-045a4](VMC-045a4.md),
[VMC-077j1](VMC-077j1.md).

A projectile and the body it strikes may occupy different 8×8-chunk sections
of the same owning group. The collision and hurt path must use that group's
authoritative stores. This is required for a dragon whose parts extend across
the End island's section lines and closes the section-local limitation in
037o. No observation grants authority across a group boundary.

Acceptance:

- An arrow hits a living target, crystal and dragon part held in a sibling
  section, using the same damage admission as a local hit. A perched part
  rejects and ignites it; crystal removal precedes its explosion.
- The shared entity change primitive fences body changes and removals by
  revision. A hurt is resolved once, retaining its random state and events;
  later projectiles in the callback see the projected result.
- Potion and cloud effects reach each living root once across the group.
- Owner tests exercise multiple targets in one tick and crash/reload after
  the source and target commit in one frame. Existing projectile, combat,
  explosion and lead flows and the affected oracle stages pass.
- The finale's graphical batch includes firing at the dragon across a
  section line. Client-pending status follows that handoff.

## Implementation and evidence (October 24, 2026)

Physical projectiles query the owning group's authoritative stores and the
players it hosts. Splash and cloud queries use living roots, excluding
crystals and avoiding duplicate dragon parts. A shared revision-fenced
entity change resolves hurt, random draws and events once, projects it into
the sibling view, and applies that same result before the group cuts its
frame. Leash changes use the same primitive. A held sibling store pauses the
projectile pass until its existing write fence clears.

Crystal removal and explosion hits update the projected stores immediately.
Deaths clear once and their resolved drops reserve IDs and enter the same
projection, so a later blast sees fresh loot. Delivery neither rerolls drops
nor repeats hurt. An immediate explosion also invalidates a worker holding
an older store, whose result retries instead of overwriting those hits.
Entity-intersection work contributes to the projectile
kernel's dirty-scheduler threshold.

The focused owner, socket, combat, projectile, explosion and group suites
pass all 48 tests, including the handoff and merge suites. Three new owner
scenarios exercise cross-section
perched-arrow ignition, flying head damage and cooldown, cloud healing once,
crystal exclusion from harmful clouds, two crystal blasts with an intervening
arrow, and a later blast destroying fresh death loot. A shared-frame crash
and reload retains both sections' changed bodies and the burning arrow;
a stale entity revision and a copied worker store are rejected. All 22
affected vanilla stages and the
publication, documentation and layering audits pass. The finale's actual
cross-section dragon shot remains the graphical gate.
