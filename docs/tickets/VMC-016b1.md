# VMC-016b1 — Persisted game modes and login permissions

Status: Done — mode initialization and permissions validated. Updated: October 14, 2026.
Depends on VMC-016a abilities and the leased player snapshot/transfer journal.

## Scope and acceptance

Establish saved current/previous mode and mode-derived login abilities/UI instead
of hardcoding creative independently in three packets and the inventory owner.
Keep the explicit creative development default. New-player configuration may
select any native mode; a saved mode takes precedence. Native survival is the
eventual default once survival gameplay exists.

- Verify native mode IDs, optional previous-mode encoding, spawn-info/player-info
  codecs and unprivileged mode requests. Never derive permissions from client or
  stored ability flags. Spectator forces flight; survival/adventure clear it.
- Persist current/optional previous modes together with flight, pose, supported
  inventory and the existing source journal. Read old records without changing
  their identity/contents; absent mode uses the configured development default.
  Reject invalid checksummed mode fields and preserve them through transfers.
- Synchronize the same mode in login and player-info. Infinite-material inventory
  permission follows that mode. Spectator clicks, hand swaps and drops cannot
  mutate owner state. Non-creative clients cannot invoke creative creation.
- Restrict the existing instant-break/free-placement preview path to creative.
  Survival mining/placement economy and adventure predicates belong to VMC-029;
  this ticket must not claim that survival gameplay is implemented. Unsupported
  world actions retain blocks/items and correct predictions.
- Parse the native change-mode request but deny unprivileged clients. No operator
  grants, client commands or live transition API are introduced by this slice.
- Pass behavior/migration/permission/recovery tests, format, full tests, release,
  full native oracle, exact diff review and public-tree audit.

Actual Minecraft 26.3 / CUA: capture fresh player context, then use trusted offline
save controls between normal disconnect/rejoin to initialize each of the four
modes. Observe survival/adventure HUD and ordinary inventory, creative catalog,
