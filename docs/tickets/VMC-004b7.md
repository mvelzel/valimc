# VMC-004b7 — Entity, block-entity, profile, book and sign data

Status: Planned
Milestone: M4
Parent: [VMC-004b](VMC-004b.md). Depends on [004b4](VMC-004b4.md).

`entity_data` and `block_entity_data` (a type and its NBT), `bees`,
`profile` (name, id, properties and skin patch), `writable_book_content`
and `written_book_content` (filterable pages), `sign_text_front` and
`sign_text_back`, and the persistent-only `lock`, `container_loot`,
`debug_stick_state` and `recipes`, which never reach the network.

Acceptance: both formats round-trip in the `item_components` stage, with
the books' page limits, the profile's property limits and the entity data's
NBT budget enforced. After this slice no 26.3 component type is refused.
