# VMC-029a3 — Fluid-preserving base block removal

Status: Native/backend and creative TCP verified; graphical gate pending.
October 16, 2026. Parent: [survival mining](VMC-029a.md).

Acceptance: native base removal leaves the original state's contained fluid,
including waterlogged blocks and flowing/falling liquids. Derive replacements
from pinned native methods for every state. Atomic region mining writes and
recovers that replacement with the same drop/receipt outcome; replay never
replaces a later block. Keep lookups immutable and reuse existing fluid indexes.

Reference: pinned Mojang26.3 jar SHA1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`,
`FluidState.createLegacyBlock` and base `Level.removeBlock` behavior. This does
not implement fluid spreading, neighbor updates or block-specific destruction
callbacks such as ice melting. Those remain separate gameplay work.

The existing20 fluid property indexes now also select a native replacement state;
all prior scalar facts/indexes remain identical. The original native probe checks
35,723 replacements and71,446 actual `Level.removeBlock` calls with controlled
fluid reads/block-write callbacks, including both moving flags. Falling liquid
levels can normalize to one falling state. Dense Elixir comparisons pass every
state; generated facts reproduce exactly. Private `.local/mining-Level.javap`.

Atomic mining prepares those replacements outside the region owner. The creative
path reads and replaces the current block in one owner call, sharing mutation
fences. Forty-seven affected tests pass: native-level boundaries, creative TCP
wet/dry removal, atomic wet removal with a real writer failure/recovery, receipt
replay after replacement, source compensation and existing fluid kernels. Logs:
`.local/mining-fluid-{native-final,check-final,tests-final}.log`; raw cases ignored.

Client scenario after live mining: remove a waterlogged supported block and
observe water retained, then reconnect and check drops/tool wear once. Delegate
to the dedicated tester; backend/native checks do not complete that GUI gate.
