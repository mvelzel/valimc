# VMC-048b1 — Hosted player piston collision response

Status: Done
Milestone: M3
Depends on: [VMC-048b](VMC-048b.md), [VMC-043e19](VMC-043e19.md).

Native players are client-authoritative and also simulate on the server. Keep
those flags separate during piston moves: retain native horizontal ground-state
behavior while applying collision response and slime impulses to server velocity.
The hosted session must retain that velocity, and Shift suppresses bounce.

Acceptance: actual native moving-piston ticks and the kernel agree for player
position, velocity and ground state with stone, slime and honey, all six faces,
extension/retraction and standing/crouching. The hosted session keeps the result;
spectators remain excluded. Actual-client testing remains deferred.

Reference: Mojang 26.3 server SHA-1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`, `Player.isClientAuthoritative`,
`getMoveSimulationType` (`AUTHORITATIVE_SIDE_AND_SERVER`), `Entity.move` and
`PistonMovingBlockEntity.moveCollidedEntities` / `moveStuckEntities`.

Implementation: the piston NIF accepts ground-state authority separately from
simulation eligibility. Hosted players enable simulation and disable local
authority, using the same external-move body as shulker lids, including Shift's
bounce suppression. The session retains velocity changes even when the piston
does not move the bounding box: overlapping slime can impart an impulse without
calling `Entity.move`. Spectators remain excluded.

Validation: `PistonPlayerOracle` runs 1,440 actual native moving-block phases
across all six directions, extension/retraction, stone/slime/honey, two origins
(including a section boundary), standing/crouching, grounded/airborne and five
placements. Position, velocity and ground state match exactly, including 80
velocity-only impulses. All 15 focused owner, player-collision, combat and
headless socket tests pass. A hosted session retains an overlapping slime's
velocity-only impulse and ignores the same push as a spectator. NIF crate tests,
workspace Clippy and compilation without parity entry points pass; Clippy has
only the six existing type-complexity warnings. Evidence:
`.local/m3-piston-player-{native,check,tests,rust,stages,audit}.log`.

All five affected native stages (`piston_player`, `pistons`, `shulker_push`,
`shulker_player_collision`, `tcp`) pass in 22 seconds, with four cache hits.

Deferred client scenario: repeat piston/slime launches and honey riding, then
crouch while a push lands on a bouncy block; observe normal continued movement.

Closed with M3 (October 31, 2026): its client observations passed in the [gate run](VMC-078.md#gate-run-on-the-native-mob-core-october-30-2026) and the [VMC-083 run](VMC-083.md#client-run-october-31-release-67a9072e).
