# VMC-045a6 — Arena features and respawn sequence

Status: Foundation
Milestone: M3
Depends on: [VMC-045a5](VMC-045a5.md).

Define the bounded arena state and native feature/ritual effects before
connecting them to the origin section's durable owner. The live integration
follows in the parent; this slice alone remains a foundation.

Acceptance:

- Active/inactive podium edits and drop intent match native placement.
- The seed's gateway order and positions match vanilla; first/repeat death
  completion changes the fight once and opens at most twenty gateways.
- Four cardinal crystal boxes admit the ritual. Its complete stage clocks,
  beams, pillar regeneration, events, final explosions and abort match native
  sequences; the caller supplies generated spike descriptions.
- Boss-bar add, remove, health, name, style and flags match native packets.
- Pure state/effects have fixed bounds; owner fencing and persistence follow
  as live integration before the parent client gate.

## Implementation and evidence (October 24, 2026)

The pure fight record fences completion by dragon UUID, grants the first
egg once and consumes the seed-shuffled gateway indices from the end. Its
ritual collects every crystal intersecting all four cardinal unit boxes,
retains stage/time/UUIDs and emits bounded beam, event, pillar, explosion
and completion effects. A destroyed participating crystal or an entirely
missing recovered crystal list aborts and restores the active exit.
The boss audience is vanilla's alive-player sphere, including creative
and spectator modes. Native add/remove/health/name/style/flag packets
match, including the compact string form of a plain literal name.

The podium uses native three-dimensional distance checks and ordered
writes, including conditional drop intent when the active feature replaces
a different block. Spike descriptions come from the existing Rust world
generator through one fixed-size pure binding; the fight has no second
spike table or shuffle implementation.

`DragonArenaOracle` calls native active/inactive feature placement over
air and clutter, and the complete respawn sequence. Four podium cases,
seven signed world seeds (seventy spike descriptions), all twenty gateway
positions, 54 boss packets and every one of the ritual's 604 ticks match.
The four focused tests cover incorrect/repeated completion, all twenty
rewards, audience boundaries, missing/extra ritual crystals, aborts and
the podium floor. The changed NIF crate tests and Rust formatting pass;
Clippy completes with only existing type-complexity warnings elsewhere.
All 52 affected vanilla stages passed, including the new arena stage and
the plain/encrypted socket check. The publication and layering audits pass.
