# VMC-056 — Runtime observability

Status: In progress
Milestone: Operations
Depends on: VMC-077 ownership and metric publications.

Interactive profiling is implemented by [VMC-056a](VMC-056a.md): spark-style
operator commands, bounded stack sampling, BEAM/process/ETS diagnostics,
per-owner ticks and local browser reports. See [profiling](../profiling.md).

The remaining operations scope is end-to-end latency/tracing and reproducible
workload records. It stays planned; the interactive profiler does not claim
native stack unwinding, exact CPU attribution or workload replay.

Acceptance for remaining slices:

- Bounded observations across owner/job/storage boundaries, with no new gameplay
  authority or simulation-owner blocking.
- Reproducible workload/configuration/revision records and meaningful latency
  distributions, with explicit sampling/retention bounds.

Checks and client evidence: see the implemented slice; remaining slices require
their own acceptance criteria and checks before implementation.
